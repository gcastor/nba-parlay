Fair % averages each book's no-vig probability for the same line, so a leg only has an edge when your book pays better than the market as a whole. Parlay probabilities multiply legs as if independent; legs from one game are correlated, which is why the default is one leg per game. Each game you pull costs one credit per prop type (regions=us), and pulled odds are kept in this browser for the day so reloading doesn't spend credits again. Not betting advice.
